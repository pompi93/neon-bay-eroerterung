# Neon Bay – Lernlandkarte „Die Erörterung“

Digitale Lernlandkarte für den Deutschunterricht (Klasse 10) zum Arbeitsheft „Die Erörterung“.
Thema aller Aufgaben: *Sollte an Schulen ein Handyverbot gelten?*

## So funktioniert es

- Sechs Missionen – eine pro Einheit des Arbeitshefts – plus Finale.
- Je Mission 8 Aufgaben mit Rückmeldung und Tipps. Bei mehr als 30 % Fehlern geht es ins Trainingslager, bei höchstens 2 Fehlern wird eine Profi-Mission freigeschaltet.
- Nach jeder Mission erscheint ein **Speichercode** (`NB-XXXX-…`). Damit spielen die Lernenden auf jedem Gerät weiter, und die Lehrkraft sieht anhand des Codes, wo es hakt.
- Der Spielstand wird nur im Browser des Geräts gespeichert. Die Seite lädt keine Inhalte von fremden Servern und speichert keine Daten auf einem Server.

## Tipp für iPads

Die Seite über „Teilen“ → „Zum Home-Bildschirm“ als App ablegen. Dann löscht Safari den Spielstand nicht nach einer Woche ohne Nutzung.
